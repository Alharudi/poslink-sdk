# POS Link SDK

Connect any cashier app to a payment terminal (Sunmi P3) over a **USB cable** or **Bluetooth**, and
take payments with one call:

```kotlin
when (val outcome = cashier.sale(amount = 12500, currency = "LYD", reference = "INV-42")) {
    is SaleOutcome.Completed -> if (outcome.result.approved) printReceipt(outcome.result)
    is SaleOutcome.Refused   -> showError(outcome.message)         // no money moved, safe to retry
    is SaleOutcome.Unknown   -> askToCheckTerminal(outcome.message) // never assume "declined"
}
```

The link is **paired once** with a 6-digit code, and every message is **signed** (HMAC-SHA256), so
a device in the middle can't fake an "approved". Duplicate-charge protection, retries, a pulled
cable and recovery of unknown outcomes are handled by the SDK.

## Android quick start

```kotlin
// settings.gradle.kts, inside dependencyResolutionManagement { repositories { … } }
maven {
    url = uri("https://alharudi.github.io/poslink-sdk/maven")
    content { includeGroup("ly.dojoon.poslink") }
}

// app/build.gradle.kts
dependencies {
    implementation("ly.dojoon.poslink:poslink-android:0.1.0")
}
```

```kotlin
// Cashier (e.g. Flex 3): connect to the paired terminal over Bluetooth
val cashier = PosLinkCashier(
    transport = BluetoothClientTransport(context, terminalBluetoothAddress), // or UsbHostTransport(context)
    identity = AndroidIdentity.load(context, name = "Front desk"),
    pairings = KeystorePairingStore(context),
    journal = FileJournal(File(context.filesDir, "poslink.json")),
)
cashier.start()

// Once per terminal: the merchant opens pairing on the terminal, the cashier types its code
cashier.pair { code -> askUserToType("Code shown on the terminal") == code }

val outcome = cashier.sale(12500, "LYD") { event -> showProgress(event) }
```

```kotlin
// Terminal (e.g. P3)
val terminal = PosLinkTerminal(
    transport = BluetoothServerTransport(context), // or UsbAccessoryTransport(context)
    identity = AndroidIdentity.load(context),
    pairings = KeystorePairingStore(context),
    journal = FileJournal(File(context.filesDir, "poslink-terminal.json")),
    payment = SimulatedPayment(), // replace with your bank app / PayLib adapter
)
terminal.start()
terminal.openPairing()            // when the merchant taps "Pair a cashier"
terminal.pairingRequest.collect { req -> req?.let { showCodeWithConfirmReject(it) } }
terminal.phase.collect { showOnScreen(it) }
```

Before the first run, do the short [Android setup](docs/android/setup.md): Bluetooth permissions,
USB intent filters, and pairing the devices in Bluetooth settings.

Running the sample: `cd android && ./gradlew :sample:installDebug`, on two devices (one cashier,
one terminal).
