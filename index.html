Dojoon · POS Link

POS Link SDK

Connect a cashier app to a Sunmi P3 payment terminal over a USB cable or Bluetooth, with a paired, signed link, and take card payments safely.

Android 0.1.0

Install (Android)

Add this address to settings.gradle.kts:

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven {
            url = uri("https://alharudi.github.io/poslink-sdk/maven")
            content { includeGroup("ly.dojoon.poslink") }
        }
    }
}

Then add the library in app/build.gradle.kts:

dependencies {
    implementation("ly.dojoon.poslink:poslink-android:0.1.0")
}
